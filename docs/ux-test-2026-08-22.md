# UX test — six personas, 2026-08-22 (night)

Six independent testers drove the live site headlessly (phone + desktop, read-only, stopped at the sign-in gate because Turnstile blocks headless submits). Personas: first-time phone user, Spanish-dominant resident, scam-wary skeptic, returning user checking a failed report, blind keyboard/screen-reader user, edge-case breaker. Screenshots under `/Users/rob/.claude/jobs/c0c6f618/tmp/ux/<persona>/`.

## Verdict
It makes sense. Every persona could file a report unaided and never mistook it for the city. Two things don't make sense yet: **the not-filed tracking page** (no why / what next, and contradictory "the city usually works these in a few days" copy) and **the finish line** (the sign-in requirement and the Cloudflare check both appear only after the reporter has done all the work). Accessibility is strong (zero contrast violations, model modal, focus rings everywhere). Spanish auto-detects and is mostly excellent, with a handful of English leaks and Castilian vocabulary.
